# 🖋️ bungo-writer (Agent Edition)

無味乾燥なコードやエラーログを文学作品に翻訳するCLIツール「bungo-writer」です。
単なるテキスト変換ツールではなく、**自律型AIエージェント（LangGraphベース）** として設計されており、自らファイルシステムを探索し、Git履歴を読み解き、最終的に一つの文学的なレポートを書き上げます。

## ✨ 特徴 (Features)

- **自律的なファイル探索と文脈理解**: 指定されたディレクトリの中身を見たり、ソースコードやGit履歴を自ら読みに行って情報をかき集めます。
- **パイプ入力からのシームレスな対話**: `cat error.log | bungo-writer` で初期コンテキストを渡した後、そのままターミナルで対話（REPL）を継続できます。
- **文学的コードレビュー機能**: プログラムを「一つの文学作品」として扱い、変数を「登場人物」、バグを「未回収の伏線」に例えて純文学の批評家のようにレビューします。
- **有機的なタイプリターUX**: 文字の出力速度にランダムな揺らぎを持たせ、句読点でタメを作るなど、まるで文豪がその場で筆を走らせているかのようなエモーショナルな体験を提供します。

## 🛠️ インストール方法 (Installation)

### 1. リポジトリのクローン
```bash
git clone https://github.com/your-username/bungo_writer.git
cd bungo_writer
```

### 2. パッケージのインストール
Python環境（仮想環境の利用を推奨）にパッケージをインストールします。
```bash
pip install -e .
```
※ これにより、ターミナルでどこからでも `bungo-writer` コマンドが使えるようになります。

### 3. APIキーの設定
プロジェクトのルートディレクトリに `.env` ファイルを作成し、使用したいLLMのAPIキーを設定してください。

```bash
# .env ファイルの例
OPENAI_API_KEY="sk-..."
GOOGLE_API_KEY="AIza..."  # Geminiを使用する場合
```

## 🚀 使い方 (Usage)

### 基本的な対話モード
ターミナルでコマンドを叩くと、指定した文豪との対話セッションが始まります。（デフォルトは夏目漱石・OpenAIモデル）
```bash
bungo-writer
```
プロンプト `>` が表示されたら、「現在のディレクトリのバグを探して」「最近のGitコミット履歴を読んで」などと話しかけてください。

### 文豪と作品の指定
`--author` と `--work` オプションで、特定の作家や作品の文体・世界観を強制できます。
```bash
bungo-writer --author "太宰治" --work "人間失格"
```

### プロバイダー（モデル）の切り替え
デフォルトはOpenAI（`gpt-4o`）ですが、Gemini（`gemini-1.5-pro`）に切り替えることも可能です。
```bash
bungo-writer --provider "gemini"
```

### パイプライン入力からの対話
エラーログや他コマンドの出力をパイプで渡し、それを初期コンテキストとして文豪に解析させることができます。解析後はそのまま対話モードに移行します。
```bash
cat error.log | bungo-writer --author "芥川龍之介"
```

### 文学的コードレビューモード (`--review`)
指定したファイルやディレクトリを「一つの文学作品」として批評させる専用モードです。自動でレビューが出力されたのち、対話モードに移行します。
```bash
bungo-writer --review src/main.py --author "夏目漱石"
```

## 🗺️ 今後の展望 (Future Roadmap)

現在の「文学的エージェント」というコンセプトをさらに拡張し、他ツールとの絶対的な差別化を図るため、以下の「尖った機能」の実装を予定しています。

### 1. 修羅場（締切直前）モード
文豪ならではの「締切に追われる姿」を再現する機能（例：`--deadline` フラグ）。
出力速度が異常に速くなり、「ああ、もう時間がない！」「編集者がドアを叩いている！」という焦燥感とともに、荒々しいが動くハックを提案してくるようになります。

### 2. 自律的な「文学的散歩（Wandering）」
ユーザーが指示を出さなくても、AIが勝手にリポジトリ内を歩き回り、適当なソースコードを立ち読みする機能（例：`bungo-writer wander`）。
気になったコードに対して「この処理は美しい…」などの手記（コメント）を勝手に生成し、プロジェクト内に残していきます。
